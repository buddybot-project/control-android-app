## 📱 Краткое описание:
**BuddyBot Control Android App** - это **Android-приложение** предназначено для управления вашим **BuddyBot** — интеллектуальной платформой с возможностью голосового взаимодействия, распознаванием лиц, мимикой, эмоциями и точным движением. Приложение реализует джойстиковое управление движением и камерой, отображает видеопоток с устройства, и позволяет отдавать команды на действия, включая озвучивание и реакцию бота.

## 🚀 Быстрый старт

### 🛠️  Сборка
```sh
./gradlew build   # На Linux/macOS
gradlew.bat build # На Windows
```

### 🧪 Запуск тестов
```sh
./gradlew test   # На Linux/macOS
gradlew.bat test # На Windows
```
